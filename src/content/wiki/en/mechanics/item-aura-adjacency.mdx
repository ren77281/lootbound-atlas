## How do aura and adjacency effects change placement?

They convert location into power, so begin with the exact wording visible in the current build and map only the cells or neighbors it clearly affects. Do not assume diagonal coverage, distance, or stacking behavior unless a tooltip or controlled comparison demonstrates the rule under the same conditions.

## How does the anchor-and-beneficiary method work?

Choose the effect that defines the cluster as its anchor, then identify the equipment that can actually receive value from it. This prevents a tidy-looking layout from hiding wasted coverage on empty cells or pieces that do not benefit.

1. Select the synergy-defining effect as the anchor.
2. List every piece that can benefit from that effect.
3. Place the least flexible beneficiary first.
4. Compare the gained effect with the inventory space consumed.

Review the [inventory rotation guide](/mechanics/inventory-grid-item-rotation) before rebuilding a large cluster.

## How can you test an unclear interaction?

Keep every variable fixed except one placement. Record the relevant before value, move or rotate one item, and observe the after value under the same conditions. Repeat the test before treating the result as a stable rule.

- Capture the tooltip and full inventory in the same record.
- Note the game version and test date.
- Avoid combining several new effects in one test.
- Mark the result as confirmed, inconsistent, or still unknown.

## What evidence is still needed?

The next evidence layer should include cell-by-cell diagrams, stacking checks, rotation comparisons, and screenshots tied to a visible game version. Until those tests exist, this page avoids universal claims about range, direction, or whether multiple copies stack.
