## What is in the Lootbound Secret Update?

The Secret Update adds an Easter egg animation that can trigger during a hero's turn. Pressing the correct keyboard or controller button gives a 10% chance to show it. The update also allows Lootbound to keep working when minimized or inactive and fixes issues involving different screen resolutions.

| Addition or fix | Confirmed detail |
| --- | --- |
| Secret animation | Can trigger during a hero's turn |
| Input | A keyboard or controller button |
| Trigger chance | 10% after pressing the correct button |
| Background behavior | The game can work while minimized or not active |
| Display fixes | Issues tied to different screen resolutions were fixed |

## Which button triggers the secret animation?

The developer deliberately did not reveal the button. The official announcement confirms that both keyboard and controller input can be used, but it does not name a key, controller mapping, timing window beyond the hero's turn, or platform-specific difference. Any exact button list currently needs independent verification.

<Callout type="warn" title="The button remains secret">A 10% trigger chance means a failed attempt does not prove that an input is wrong. This page will not label a button as confirmed without repeatable evidence or a later developer disclosure.</Callout>

The announcement also does not describe an item, achievement, stat change, or other reward for triggering the animation. Until such an effect is documented, it is safest to treat the discovery as a visual Easter egg rather than a progression requirement.

## Can Lootbound continue while it is minimized?

Yes. The Secret Update states that Lootbound now works while minimized or when its window is not active. The notes do not define which animations, turn states, audio behaviors, or controller inputs continue in the background, so those details should be checked on the current build rather than inferred.

If you are validating controls or display behavior for the first time, start with the [Lootbound first-run guide](/guides/first-run-guide), which records platform-visible facts separately from observations that may change with a patch.
