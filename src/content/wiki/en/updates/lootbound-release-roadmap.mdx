## When did Lootbound release?

Lootbound released on Steam on August 14, 2026. ArtDock's launch announcement says the game reached release after about two years of development and describes this release as the beginning of its next stage, with several post-launch updates already being worked on.

The announcement included a 35% launch discount for the first two weeks. That was a time-limited launch offer, not a statement about the game's current price. Check the Steam store directly for today's price and availability.

## What is Lootbound's core gameplay loop?

The developer describes Lootbound as a roguelite in which each run comes together differently. Players choose routes, fight enemies, collect loot, experiment with upgrades, and adjust their build during a run. The official release post emphasizes experimentation alongside winning rather than publishing a fixed best route or build.

| Part of a run | Confirmed launch description |
| --- | --- |
| Route | Choose a path through the run |
| Combat | Fight enemies along that route |
| Loot | Collect items and pursue more valuable rewards |
| Upgrades | Experiment with upgrades as the run develops |
| Build | Change the setup during a run when needed |

The [beginner guide](/guides/beginner-guide) provides a cautious starting framework, while the [route risk-and-reward guide](/guides/map-routes-risk-reward) focuses on decisions that can be checked without inventing hidden odds.

## What has ArtDock confirmed for the post-launch roadmap?

ArtDock confirms that several post-release updates are in development and says it intends to make Lootbound bigger, more varied, and better. The launch announcement does not name those updates, list their features, or provide a release schedule, so more specific roadmap claims remain unconfirmed.

<Callout type="info" title="Roadmap scope">“Several updates are in development” is the complete confirmed commitment in the launch post. Feature lists and dates should only be added after a separate official announcement.</Callout>

Later official posts delivered Patches [1.1.5](/updates/patch-1-1-5) and [1.1.7](/updates/patch-1-1-7), plus the [Secret Update](/updates/secret-update). Those releases confirm continued post-launch work, but they do not establish dates for anything beyond the updates already published.
