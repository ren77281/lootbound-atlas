## Which Paladin details are still missing?

Current ability text, activation conditions, compatible equipment, and the tradeoff between defensive value and inventory space all need dated captures. The page also needs a complete run record showing when the setup begins to function and whether a poor early draw leaves a practical fallback.

## What will make the Paladin guide publishable?

Each claim must cite visible in-game wording or a controlled comparison, while the final layout needs screenshots tied to one game version. The [inventory grid guide](/mechanics/inventory-grid-item-rotation) remains the safer reference until those class-specific checks are complete.
