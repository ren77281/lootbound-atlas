## What should you do before your first Lootbound run?

Open the official Steam listing and confirm which build is currently available. Old guides can become stale after release or a patch. Once in game, focus on learning how systems respond to one change at a time rather than trying to memorize unverified lists of items, rooms, or exact values.

## What should you learn in the first session?

Use the first session to observe placement and route feedback. These checks create knowledge that remains useful when the balance changes because they focus on how to test a decision rather than one fixed answer.

1. Rotate item shapes and watch which layouts remain flexible.
2. Observe which relationships update immediately after a move.
3. Read every route choice before selecting it.
4. Use dice decisions to learn failure cost, not chase every maximum reward.
5. Note how companions and Guardian parts alter the run's direction.

Start with the broader [beginner guide](/guides/beginner-guide) when you want a complete run-planning framework.

## What belongs in a useful bug report?

Record the visible game version, platform, input method, reproduction steps, and a screenshot that includes the complete inventory or decision screen. Version context matters because a mechanic can change after a patch, making an otherwise accurate report difficult to reproduce later.

## How do you move beyond the tutorial mindset?

Once every piece has a reason for occupying its current cell, test one focused hypothesis per run: a placement rule, companion interaction, route threshold, or Guardian direction. Focused runs produce cleaner evidence than trying to discover every system at once.
